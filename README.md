# chesler-lab
Welcome to the chesler-lab repository. Here you will find applicable code and analyses for projects and initiatives associated with the Chesler Lab. See https://www.jax.org/research-and-faculty/research-labs/the-chesler-lab for more information.

### Repo Organization
The repo includes a folder for each project. Project folders contain all applicable code and analyses. Below you will find information on each project folder.

#### Projects

##### strain-recommender
- `recommender` - R package for running the strain recommender approach
- `transcriptome.imputation` - R package for running the transcriptome imputation pipeline
- `supporting-analyses` - includes all analysis code used to generate results in the manuscript
